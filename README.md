# Hanja Constellation Web

A mobile-first, installable web app for practicing 105 essential Hanja through Korean vocabulary constellations.

## Features

- 105 daily Hanja lessons and 525 original vocabulary examples
- Meaning Match, Sentence Blank, Word Builder, Hanja Detective, and Speed Round
- Local XP, streaks, lesson completion, and unlocking
- Offline support through a service worker
- No accounts, analytics, cookies, or server-side data storage

## Run locally

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080`.

## Source

The character sequence follows HowToStudyKorean's Hanja Unit 1, Lessons 1-20. All vocabulary selections, mnemonics, sentences, translations, and game implementation in this repository are original.
